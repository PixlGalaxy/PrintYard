# Creality K2 SE profiles (bundled snapshot)

These JSON files are copied unchanged from **Creality Print v7.3.1** (tag `v7.3.1`, commit `254250c`),
`resources/profiles/Creality/` and `resources/profiles/BBL/cli_config.json`:
<https://github.com/CrealityOfficial/CrealityPrint>.

Included: every preset compatible with `Creality K2 SE 0.4 nozzle` (1 machine, 3 processes, 20 filaments), the
machine model, and every `inherits` ancestor (`fdm_*_common`, `fdm_filament_<type>`, …). `Creality.json` is the
original vendor index reduced to these entries (same order, same `version`).

PrintYard uses this snapshot when no engine is installed; once an engine is installed, the profiles inside the
extracted AppImage are used instead.
